Discos duros

HDD: Hard Disk Drive

Un disco duro o HDD (Hard disk drive) es un dispositivo de almacenamiento de datos que utiliza un sistema magnético guardar y recuperar archivos digitales de forma permanete.

SSD: Solid State Drive

Un SSD (Solid State Drive) es un dispositivo de almacenamiento de datos que guarda la información usando chips de memoria electrónico en lugar de discos magnéticos.

Fuente de Alimentación ATX

Una fuente de alimentación ATX es un dispositivo que convierte la corriente alterna (AC) de la toma de corriente en corriente continua (DC) necesaria para alimentar los componentes internos de una computadora.

Lector de Discos

Un lector de discos es un dispositivo que permite leer y escribir datos en discos ópticos, como CD, DVD o Blu-ray.
